# Vedant Shrivastava - Modern 3D Developer Portfolio

An interactive, high-performance 3D developer portfolio showcasing full-stack projects, achievements, and technical expertise. Built with **React 19**, **Three.js / React Three Fiber**, and **GSAP ScrollTrigger**.

![Portfolio Preview](/public/profile.jpg)

## ✨ Features

- **Interactive 3D Scene**: Custom animated 3D DNA Helix structure with glowing particle nodes and dynamic starfield rendered using `@react-three/fiber` and `@react-three/postprocessing`.
- **GSAP Scroll-Scrubbed Architecture**: Smooth, cinematic scroll navigation with section weight distribution and responsive 3D camera movements.
- **Projects Showcase**: Interactive cards featuring **Smart Internship Portal** and **AI Resume Builder** with live deployment links and tech stacks.
- **Achievements Section**: Sequential 3D card sequence with glowing border aesthetics, highlighting competitive hackathons and open-source contributions.
- **Terminal Aesthetic Contact**: Scramble text terminal animation, social links (LinkedIn, GitHub), and direct email interaction.
- **Modern Responsive Design**: Clean dark aesthetic with glassmorphism, glowing accents (`#3ee6a8`), and smooth typography.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS v4
- **3D Graphics & Shaders**: Three.js, React Three Fiber (R3F), Drei, Postprocessing, GLSL shaders
- **Animation**: GSAP, ScrollTrigger, ScrollToPlugin, `@gsap/react`
- **State Management**: Zustand
- **Code Quality**: Oxlint

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vedant-175/My-Portfolio-.git
   cd My-Portfolio-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
